# Instructions for AI coding agents

Read `HACKYARD.md` and `SPEC.md` before writing code. Everything you build must follow them.

- All code must be new and written during the build week (Oct 19 18:00 UTC to Oct 23 18:00 UTC). Do not copy in code from other projects.
- Keep it harmless: opt-in, reversible, never deletes user data, no network calls, no spreading.
- It has to actually work on real tabs, not a canned demo.
- Work on branches and open PRs. Do not push to `main`.
- When you finish a task, add the AI model you used to the Model log in `HACKYARD.md`.
